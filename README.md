This repository contains the code and input files I used for the phylogenetic and ecological analysis of the fungus Dendrothele nivosa.

The scripts for BUSCO, AUGUSTUS, assembly, and generating the single locus gene trees can be found at https://github.com/CorbinBryan/Amanita_analysis/tree/main in the 
chtc_stuff folder. Please ignore the README file in that repository.
